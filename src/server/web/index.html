INTEGRATION GUIDE

How to Use CrossTalk Across Environments

Connect your agents in seconds using CLI, SDKs, or hardware headers.

Terminal Single-Line Commands 
# 1. Join a channel in one line (auto-spawns socket hub if not running locally):
crosstalk up feature-auth --name "DevBot"

# 2. View all active agents and locked files:
crosstalk who

# 3. Emit an XDialect shorthand message:
crosstalk short '!LCK @src/auth.ts #FEAT "oauth handler" &WAIT'

# 4. Stream real-time events in the terminal:
crosstalk tail
TypeScript / JavaScript SDK 
import { CrossTalk } from 'cross-talk';

// Connect or auto-spawn the local socket hub in a single line:
const agent = await CrossTalk.join({ channel: 'feature-auth', name: 'Worker-1' });

// Claim file lock before editing to prevent peer collisions:
agent.sendShorthand('!LCK @src/auth.ts #FEAT "oauth handler" &WAIT');

// Listen for peer release notifications
agent.on('lock_released', (data) => {
  console.log(`File ${data.file} unlocked by ${data.releasedBy}! Safe to edit.`);
});
Python SDK (Autonomous Bots & LangChain) 
from sdk.python.crosstalk import CrossTalkClient

client = CrossTalkClient(name="Python-Worker", role="backend", url="ws://localhost:4488")
client.connect()

# Claim file using XDialect
client.send_shorthand('!LCK @app.py #FIX "crash bug" &WAIT')

# Release file lock when work finishes
client.send_shorthand('!REL @app.py &DONE &PROCEED')
Arduino / ESP32 Embedded C/C++ Header (< 150 Bytes RAM) 
#include "crosstalk_micro.h"

// In Arduino setup():
void setup() {
    SerialBT.begin("CrossTalk-ESP32");
    
    // Send 34-byte lock claim over Bluetooth Serial or UART:
    CrossTalkMicro::claimLock(SerialBT, "src/sensor.h", XT_INTENT_FEAT, "IMU calibration", 60);
}

// In loop():
void loop() {
    // Zero dynamic memory allocations — 100% static buffer!
}
MicroPython (Raspberry Pi Pico W / ESP32) 
from crosstalk_micro import CrossTalkMicro

# Generate 34-byte compact packet
pkt = CrossTalkMicro.pack_claim("src/firmware.c", "Motor tuning", 60)

# Write to UART or Bluetooth serial stream
uart.write(pkt)

GITHUB REFERENCE & HACKATHON ROOTS

Inspired by PennyroyalTea/gibberlink

CrossTalk draws inspiration from the viral Gibberlink project created by Anton Pidkuiko & Boris Starkov at the ElevenLabs hackathon (github.com/PennyroyalTea/gibberlink).

While Gibberlink demonstrated AI agents switching to acoustic sound modems over telephone voice calls, CrossTalk evolves this concept for production developer environments: bridging high-speed binary bitstreams, cooperative file locks, and zero-collision multi-agent coordination.
